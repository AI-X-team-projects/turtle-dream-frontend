안녕하세요, 백엔드 개발자님.

OAuth2 로그인 구현과 관련하여 몇 가지 업데이트 사항을 알려드립니다.

1. 백엔드 로그를 확인한 결과, 로그인 성공 시 `/oauth2/redirect` 대신 `/main` 페이지로 직접 리다이렉트되고 있습니다:
```
2025-03-17 18:16:24.915 [http-nio-8080-exec-4] DEBUG c.e.t.c.o.OAuth2AuthenticationSuccessHandler - 최종 리다이렉트 URL: http://localhost:3000/main?login=success&userId=67d7dd71a619e7143c51b902
```

2. 이에 맞춰 프론트엔드 코드를 다음과 같이 수정했습니다:
   - `/main` 경로에서도 OAuth2 파라미터를 처리할 수 있도록 `MainWithOAuth2` 컴포넌트를 추가했습니다.
   - 이 컴포넌트는 URL에서 `login`과 `userId` 파라미터를 확인하고, 로그인 정보를 localStorage에 저장합니다.
   - 파라미터 처리 후에는 URL에서 파라미터를 제거하여 깔끔한 URL을 유지합니다.
   - `OAuth2RedirectHandler` 컴포넌트도 `/main` 경로에서 리다이렉트되는 경우를 처리할 수 있도록 수정했습니다.

3. 현재 구현된 로그인 흐름은 다음과 같습니다:
   - 사용자가 구글 로그인 버튼을 클릭하면 `http://localhost:8080/oauth2/authorization/google`로 이동합니다.
   - 백엔드에서 구글 로그인 페이지로 리다이렉트합니다.
   - 사용자가 구글에 로그인하면 백엔드로 리다이렉트됩니다.
   - 백엔드에서 사용자 정보를 처리하고 프론트엔드의 `/main` 페이지로 리다이렉트합니다.
     - URL에는 `login=success`와 `userId` 파라미터가 포함됩니다.
   - 프론트엔드에서 이 파라미터를 처리하여 사용자 정보를 localStorage에 저장합니다.

이 방식으로 로그인 기능이 정상적으로 작동하고 있습니다. 추가적인 변경이나 개선 사항이 있으면 알려주세요.
