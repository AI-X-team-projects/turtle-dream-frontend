안녕하세요, 백엔드 개발자님.

구글 OAuth2 로그인 시도 중 다음과 같은 오류 페이지가 나타납니다:

```
Whitelabel Error Page
This application has no explicit mapping for /error, so you are seeing this as a fallback.

Mon Mar 17 18:00:41 KST 2025
There was an unexpected error (type=Not Found, status=404).
```

URL: `http://localhost:8080/oauth2/authorize/google`

이 오류는 백엔드 서버에서 `/oauth2/authorize/google` 엔드포인트를 찾을 수 없다는 의미입니다. 다음 사항을 확인해주세요:

1. Spring Security OAuth2 클라이언트 설정이 올바르게 되어 있는지 확인:
   - `application.yml` 또는 `application.properties` 파일에 구글 OAuth2 클라이언트 ID와 시크릿이 올바르게 설정되어 있는지
   - OAuth2 관련 의존성이 `pom.xml` 또는 `build.gradle`에 추가되어 있는지

2. OAuth2 인증 컨트롤러가 구현되어 있는지 확인:
   - `/oauth2/authorize/{provider}` 엔드포인트를 처리하는 컨트롤러가 있는지
   - 해당 컨트롤러가 Spring Security 설정에 등록되어 있는지

3. Spring Security 설정에서 OAuth2 로그인이 활성화되어 있는지 확인:
   ```java
   @Configuration
   @EnableWebSecurity
   public class SecurityConfig extends WebSecurityConfigurerAdapter {
       @Override
       protected void configure(HttpSecurity http) throws Exception {
           http
               .oauth2Login()
               .authorizationEndpoint()
               .baseUri("/oauth2/authorize")
               // ...
       }
   }
   ```

4. 로그 확인:
   - 서버 로그에서 OAuth2 관련 오류 메시지가 있는지 확인
   - 디버그 모드로 실행하여 더 자세한 정보 확인

임시 해결책으로, 구글 개발자 콘솔에서 직접 OAuth2 인증 URL을 사용할 수 있습니다:
```
https://accounts.google.com/o/oauth2/auth?client_id=[YOUR_CLIENT_ID]&redirect_uri=http://localhost:8080/login/oauth2/code/google&response_type=code&scope=email%20profile
```

위 URL에서 [YOUR_CLIENT_ID]를 실제 구글 클라이언트 ID로 변경하여 사용해보세요.

감사합니다.
