안녕하세요, 백엔드 개발자님.

구글 OAuth2 로그인 구현 중 다음과 같은 오류가 발생했습니다:

```
경고: The HTTP response header [Location] with value [http://localhost:8080/main?login=success&name=으엉] has been removed from the response because it is invalid
java.lang.IllegalArgumentException: The Unicode character [으] at code point [51,004] cannot be encoded as it is outside the permitted range of 0 to 255
```

이 문제는 리다이렉트 URL에 한글 이름이 포함되어 발생하는 인코딩 문제입니다. 다음과 같은 변경을 요청드립니다:

1. OAuth2 인증 성공 후 리다이렉트 URL을 다음과 같이 변경해주세요:
   - 현재: `http://localhost:8080/main?login=success&name=한글이름`
   - 변경: `http://localhost:3000/main` (프론트엔드 메인 페이지로 직접 리다이렉트)

2. 또는 다음 두 가지 방법 중 하나를 선택해주세요:
   a) 리다이렉트 URL에 한글 이름을 포함하지 말고, 사용자 ID만 포함하도록 변경:
      `http://localhost:3000/main?userId=123`
   
   b) 한글 이름을 URL 인코딩하여 전달:
      `http://localhost:3000/main?name=${encodeURIComponent('한글이름')}`

3. 프론트엔드에서는 다음과 같이 변경했습니다:
   - 구글 로그인 콜백을 처리하는 `/login/oauth2/code/google` 경로를 추가했습니다.
   - 로그인 성공 시 사용자 정보를 localStorage에 저장하고 `/main` 페이지로 리다이렉트합니다.

4. 백엔드에서 다음 API 엔드포인트를 추가해주시면 더 좋을 것 같습니다:
   - `GET /api/oauth2/callback/google?code={code}&state={state}`: 구글 인증 코드를 처리하고 사용자 정보를 반환하는 API
